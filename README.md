# 2D game
The project now has a dog that can do different things like jump, run and fall. Its set on a background that uses a parallax scrolling effect. 
In the future I'm turning this project into a game. In the game the dog has to face lots of monsters and obstacles. The dog needs to beat these problems and get to the boss. 
Then the dog can leave this place. Go back, to his normal life.
# Play the Game

[TRY IT ](https://game-js-ebon.vercel.app/)

## How to Run

Download this repository.
Open `index.html` in your browser.

## Features
The dog can switch between different animations.
The dog can perform actions like jumping, running and sitting by selecting them from the dropdown menu.
The background has a parallax scrolling effect.
These are the features that are available right now; the project is still being worked on.

## Built With
HTML
CSS
JavaScript

## How It Works
JavaScript manages the dog animations and the background scrolling. The animation changes based on the option you pick. Different background layers move at speeds to give a parallax effect.
HTML sets up the page structure. CSS handles the styling.
